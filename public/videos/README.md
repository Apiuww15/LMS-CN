# Background video halaman login EduCN

1. Siapkan video MP4 (H.264 + AAC atau tanpa audio), idealnya 1920×1080, 15–30 detik, dan ukuran terkompresi yang wajar.
2. Letakkan file video di folder ini dengan nama tepat `login-background.mp4`.
3. Path akhirnya harus `public/videos/login-background.mp4`.
4. Jalankan ulang `npm run dev` atau deploy ulang aplikasi.
5. Video akan autoplay, muted, loop, dan playsInline. Jika file belum ada/gagal dimuat, background gambar sekolah otomatis tetap digunakan.
6. Untuk mengganti video, timpa file dengan nama yang sama. Jangan menambahkan audio wajib karena autoplay browser dibatasi.
