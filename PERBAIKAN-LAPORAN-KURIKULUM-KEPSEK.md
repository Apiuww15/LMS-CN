# Perbaikan Laporan Kurikulum/Kepsek

- Menu Mata Pelajaran dapat dikelola oleh Admin dan Kurikulum. Kepsek tidak mendapat menu maupun izin tulis mapel.
- Generate laporan menyediakan Data Guru, Data Siswa, dan Rekap Kelas; opsi Nilai dan Kehadiran serta input Periode dihapus.
- Generate laporan membuat file unduhan aktual dalam PDF, Word-compatible `.doc`, Excel `.xlsx`, atau CSV dari data MongoDB.
- Riwayat laporan menyimpan nama, tanggal, format, dan status tanpa kolom Periode.
- Halaman Aktivitas hanya menampilkan Riwayat Aktivitas; panel Status Keamanan, Total Event, dan Periode Realtime dihapus.
- Menu Aktivitas tersedia untuk semua role dan menampilkan event yang tersimpan.
